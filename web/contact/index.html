Frequently Asked Contact Questions

Can I embed Karakorum API in my commercial application?

Yes. Our REST API accepts `multipart/form-data` payloads up to 100MB per request. For custom on-premise deployments or higher payload limits, email us at summati@zohomail.in.

How do I report a security vulnerability?

If you identify any security vulnerability regarding in-memory buffers or data parsing, please email us directly with a reproducible PoC rather than posting publicly on GitHub.
